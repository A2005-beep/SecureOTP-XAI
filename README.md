🛡️ SecureOTPXAI
SecureOTPXAI is a modern, privacy-first Android application designed to protect users from SMS phishing (Smishing), OTP theft, and social engineering attacks.

Built with a state-of-the-art Hybrid Intelligence Architecture, the app combines rapid on-device LSTM Machine Learning models with rigorous heuristic rules to assign real-time threat scores to incoming messages. To ensure maximum accuracy, it integrates a cloud-based Relevance AI Agent that performs deep contextual verification of suspicious messages.

✨ Key Features:
🤖 Hybrid AI Analysis: Combines offline LSTM inference with cloud-based AI to detect advanced fraud patterns.
🧠 Explainable AI (XAI): Doesn't just block threats—it explains why a message is dangerous using human-readable logic and confidence scores.
💣 SMS Bombing Protection: Automatically detects and mitigates rapid-fire SMS denial-of-service attacks.
🎨 Premium Cyber UI: A sleek, dark-themed, responsive dashboard built with Android RecyclerView and color-coded threat levels.
💾 Offline Persistence: Uses Android Room Database and MVVM architecture to securely store threat logs locally on the device.
