🛡️ SecureOTPXAI
SecureOTPXAI is a modern, privacy-first Android application designed to protect users from SMS phishing (Smishing), OTP theft, and social engineering attacks.

Built with a state-of-the-art Hybrid Intelligence Architecture, the app combines rapid on-device LSTM Machine Learning models with rigorous heuristic rules to assign real-time threat scores to incoming messages. Designed with security in mind, the entire analysis pipeline runs 100% offline on your device, ensuring your sensitive messages and OTPs never leave your phone.

✨ Key Features:
🤖 100% Offline Hybrid AI: Combines on-device LSTM inference with a heuristic rule engine to detect advanced fraud patterns instantly without needing an internet connection.
🧠 Explainable AI (XAI): Doesn't just block threats—it explains why a message is dangerous using human-readable logic and confidence scoring.
💣 SMS Bombing Protection: Automatically detects and mitigates rapid-fire SMS denial-of-service attacks.
🎨 Premium Cyber UI: A sleek, dark-themed, responsive dashboard built with Android RecyclerView and color-coded threat levels.
💾 Secure Local Persistence: Uses Android Room Database and MVVM architecture to securely store threat logs locally on the device, ensuring total privacy.
🚀 Future Scope
To transform SecureOTPXAI into a comprehensive mobile security suite, the following modules are planned for future development:

📱 App Risk Analyzer: A system-wide scanner that analyzes all installed applications on the user's device. It will evaluate permissions, background behaviors, and known malicious signatures to detect and flag high-risk or spyware apps that could potentially compromise OTPs or personal data.
📊 Global Threat Dashboard: A centralized, interactive command center that aggregates data from both the SMS and App analyzers. This dashboard will provide users with a "Global Security Score," visual threat heatmaps, and actionable recommendations—making it incredibly easy for non-technical users to understand their overall device health and address vulnerabilities instantly.
